| 去重：语义相似度 >95% | ❌ | 完全缺失 |
| 降噪：与 L3 低信源列表对比 | ❌ | 完全缺失 |

## 六、高优先级遗漏项（v2 报告未评估）

### 6.1 登录页面 — 前端完全缺失

- **后端**: `auth.py` 已实现 JWT 认证（login/register/me），默认用户 admin/admin123
- **前端**: 无 `/login` 路由，无登录页面组件，无路由守卫，无认证状态管理
- **Spec F029 要求**: 10 个页面中包含 Login 页面
- **影响**: JWT 认证（G4）即使修复也无法使用——没有登录页就无法获取 token

### 6.2 F019 信号管线 — API/前端未暴露

- **后端**: `signal.py` 完整实现 Signal/SignalManager/convert_ai_to_strategy/信号冲突解决
- **API**: 无信号管线端点
- **前端**: 无信号交互页面
- **Spec 要求**: F019 是 P0 功能，信号优先级矩阵、A 股规则约束、信号过期机制

### 6.3 Agent Orchestrator — 完全未实现

- **Spec 要求**: AI Agent Orchestrator 中枢架构（策略编排+信号融合+决策推荐+风险审核）
- **当前**: 各 Agent 独立运行，无统一协调层
- **影响**: Spec 2.1 核心设计理念中的 AI 原生架构无法闭环

### 6.4 AIEvent 事件总线 — 未用于 Agent 间通信

- **Spec 要求**: 所有 AI Agent 通过 AIEvent 事件总线通信（异步事件驱动+同步请求/响应+共享内存）
- **当前**: EventType 枚举定义了 4/5 种 AI 事件类型，但 EventEngine 未用于 Agent 间通信
- **影响**: DataAgent→NewsEvent→MonitorAgent/DecisionAgent 的异步通信模式未实现

### 6.5 F013 报表生成 — API/前端未暴露

- **后端**: `report.py` 已实现 HTML/JSON 报表生成（缺 PDF）
- **API**: 无报表端点
- **前端**: 无报表下载按钮
- **Spec 要求**: HTML（默认）+ PDF（可选）+ JSON（机器可读）

### 6.6 调度器 — API/前端未暴露

- **后端**: `scheduler.py` 完整实现定时调度
- **API**: 无调度端点
- **前端**: 无调度管理页面
- **Spec 要求**: 定时报告（每日收盘后推送日总结）、定时数据采集

### 6.7 通知通道 — 前端仅 4/9 可配置

- **后端**: 7/9 通道有 Settings 配置项（缺 ServerChan 和 Webhook）
- **前端 NotifierForm**: 仅 DingTalk/企业微信/Telegram/邮件 4 个通道
- **缺失**: 飞书/Discord/PushPlus/ServerChan/Webhook 无前端配置 UI

### 6.8 F012 PaperBroker — 骨架无实时数据

- **当前**: PaperBroker 撮合逻辑可用，但 get_positions()/get_balance()/get_history() 返回空/硬编码
- **Spec 要求**: 使用实时行情模拟成交，与 BacktestBroker 相同费用模型
- **影响**: 交易页面（T7）的 Paper 模式无法真正运行模拟盘

## 十、核心建议

1. **F020 必须拆细**：当前 3 条任务无法覆盖 Spec 350+ 行的精细要求。建议拆为至少 15-20 条子任务，每个环节的每个子步骤独立跟踪。

2. **依赖链必须显式标注**：F020→F024→F025 是一条严格的依赖链。F020 未实现则 F024/F025 无法完整运作。实施顺序必须保证 F020 先行。

3. **登录页面是 JWT 认证的前置条件**：G4（JWT 认证实质生效）没有登录页面就无法使用，必须将登录页实现纳入 Phase 1。

4. **NFR 测试不应是 P2**：性能和可靠性指标应在每个 Phase 完成后验证，而非最后统一测试。建议每个 Phase 增加验收测试步骤。

5. **F030 部署方案需要独立详细计划**：当前一句话描述无法覆盖 Spec 的 7 项核心要求，需要独立的部署实施计划。

6. **v2 报告达标率可能高估 10%**：多个 ⚠️ 项的实际差距比标记的更大，建议对 Backtest/Strategy/Data 的 100% 达标率做端到端验证。
