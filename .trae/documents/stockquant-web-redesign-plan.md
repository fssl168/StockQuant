## 一、PRFAQ

### Press Release

**标题：StockQuant v2 Web Dashboard — 对标机构级的量化交易前端平台**

我们发布 StockQuant v2 Web Dashboard，一个基于 React + Ant Design + ECharts 构建的机构级量化交易平台前端。该平台覆盖量化交易的完整生命周期：从策略编写与回测配置，到回测结果深度分析、实时盯盘监控、投资组合管理、AI 辅助决策与对话，以及系统级参数配置。

StockQuant v2 的核心差异化在于：
1. **AI 原生集成**：内建 AI 策略生成（F022）与 AI 辅助决策（F025），用户可以用自然语言描述策略意图，AI 自动生成可执行代码并回测验证。
2. **深色主题专业级 UI**：专为长时间盯盘和数据密集型操作设计的深色界面，降低视觉疲劳。
3. **实时通信**：WebSocket 推送回测进度与实时行情，SSE 流式 AI 对话输出，延迟低于 500ms。
4. **完整指标体系**：30+ 专业回测指标（Sharpe、Sortino、Calmar、VaR、CVaR、SQN 等），结构化分组展示。

### FAQ

**Q1: 目标用户是谁？**
A1: 三类用户：(1) 量化策略开发工程师 — 需要代码编辑器、参数配置、回测验证；(2) 投资分析师 — 需要策略管理、回测结果分析、AI 辅助决策；(3) 系统管理员 — 需要数据源配置、AI 模型管理、通知推送设置。

**Q2: 关键使用场景？**
A2: 每日晨间复盘（仪表盘概览）→ 策略开发/修改（策略编辑器）→ 参数回测（回测配置）→ 结果分析（回测结果页）→ 信号监控（盯盘页面）→ 交易决策（AI 辅助）→ 系统配置更新（设置页面）。

**Q4: 为何现在做？**
A4: F022/F025 AI Agent 已实现，需要前端界面来暴露 AI 能力。现有前端代码架构完整但视觉体验未达到机构级标准，需要重构。

**Q5: 成功指标？**
A5: 首屏加载 < 3s；图表渲染 < 2s；WebSocket 推送延迟 < 500ms；Lighthouse >= 80。

**Q6: 边界与不做什么？**
A6: 不实现 F016 Streamlit Dashboard（与 F029 React 方案并行）。不包含真实的券商交易执行（仅模拟盘）。不包含参数优化页面的完整实现。

## 五、视觉与交互交付方案

### 页面结构

**Dashboard**（3 区块自上而下）：
1. 指标卡片区：6 个卡片等宽网格，小屏 2 列，中屏 3 列，大屏 6 列
2. 图表区：左右分栏（权益曲线占 2/3，AI 信号占 1/3）
3. 表格区：回测历史完整宽度

**Strategy**（左右分栏）：
1. 左侧：Monaco Editor（70% 宽度），含工具栏（保存/加载模板/语法检查）
2. 右侧：策略列表 + 预览面板

**Settings**（单栏）：
1. 顶部：模式切换 + 批量操作
2. 主体：Collapse 手风琴（14 分组），每组 2 列表单布局
3. 底部：浮动保存条
