#### Task 6: 引入 openapi-typescript-codegen

**目标**：前端自动从后端 OpenAPI 生成 TypeScript 类型

**文件**：
- `web/package.json` — 添加 devDependency 和 script
- `web/openapi-config.json` — 新建配置文件
- `web/src/generated/` — 新建目录（自动生成）

**实施步骤**：
1. 在 `web/package.json` 的 `devDependencies` 添加：
   ```json
   "openapi-typescript-codegen": "^0.29.0"
   ```
2. 在 `web/package.json` 的 `scripts` 添加：
   ```json
   "generate-api": "openapi --input http://localhost:8000/openapi.json --output ./src/generated --client axios --useOptions --useUnionTypes"
   ```
3. 新建 `web/openapi-config.json`：
   ```json
   {
     "input": "http://localhost:8000/openapi.json",
     "output": "./src/generated",
     "client": "axios",
     "useOptions": true,
     "useUnionTypes": true
   }
   ```
4. 运行 `npm install` 安装依赖
5. 启动后端，运行 `npm run generate-api` 生成类型

**验证**：`web/src/generated/` 目录下有 `services/` 和 `models/` 子目录

#### Task 7: 前端删除 snakeToCamel 运行时转换

**前置条件**：Task 5、Task 6 完成后

**目标**：后端已返回 camelCase，前端无需运行时转换

**文件**：
- `web/src/api/client.ts` — 删除 `snakeToCamel()` 函数，简化响应拦截器

**实施步骤**：
1. 删除 `client.ts` 第 3-25 行的 `snakeToCamel` 函数
2. 修改第 51-56 行响应拦截器：
   ```typescript
   client.interceptors.response.use(
     (r) => r.data,  // 直接返回，不做 key 转换
     (error) => {
       const status = error.response?.status
       if (status === 401) {
         try { localStorage.removeItem('auth_token') } catch { /* ignore */ }
       }
       const msg = error.response?.data?.detail || error.message || '请求失败'
       return Promise.reject(new Error(msg))
     },
   )
   ```
3. **关键风险点**：删除 snakeToCamel 后，前端代码中所有 `snake_case` 字段访问需改为 `camelCase`
   - 检查 `web/src/stores/*.ts`（8 个 store）
   - 检查 `web/src/pages/*.tsx`（17 个页面）
   - 检查 `web/src/components/**/*.tsx`（26 个组件）
4. **渐进策略**：先 grep 出所有 `snake_case` 字段访问点，逐个替换为 camelCase
5. 由于 client.ts 第 14 行有特殊处理：`if (key === 'task_id' || key.endsWith('_id') || key === 'id')` 跳过转换，需特别检查这些字段

### P2 — 数据库迁移收尾

#### Task 8: 创建缺失的 Alembic 迁移脚本

**目标**：完成 Phase 9 数据库迁移方案中剩余的 migration_2 和 migration_3

**文件**：
- `migrations/versions/005_jsonb_migration.py` — 新建
- `migrations/versions/006_add_indexes.py` — 新建

**实施步骤**：

1. 新建 `005_jsonb_migration.py`：
   ```python
   revision = '005_jsonb_migration'
   down_revision = '004_drop_pending_orders'

   def upgrade() -> None:
       import sqlalchemy as sa
       from sqlalchemy.dialects import postgresql
       # 仅 PostgreSQL 执行 JSONB 迁移；SQLite 跳过
       bind = op.get_bind()
       if bind.dialect.name == 'postgresql':
           op.alter_column('backtest_results', 'metrics',
               type_=postgresql.JSONB(astext_type=sa.Text()),
               postgresql_using='metrics::jsonb')
           op.alter_column('backtest_results', 'equity_curve',
               type_=postgresql.JSONB(astext_type=sa.Text()),
               postgresql_using='equity_curve::jsonb')

   def downgrade() -> None:
       bind = op.get_bind()
       if bind.dialect.name == 'postgresql':
           op.alter_column('backtest_results', 'metrics', type_=sa.Text())
           op.alter_column('backtest_results', 'equity_curve', type_=sa.Text())
   ```

2. 新建 `006_add_indexes.py`：
   ```python
   revision = '006_add_indexes'
   down_revision = '005_jsonb_migration'

   def upgrade() -> None:
       op.create_index('ix_orders_user_status', 'orders', ['user_id', 'status'])
       op.create_index('ix_positions_user_symbol', 'positions', ['user_id', 'symbol'], unique=True)

   def downgrade() -> None:
       op.drop_index('ix_positions_user_symbol', table_name='positions')
       op.drop_index('ix_orders_user_status', table_name='orders')
   ```

## 四、假设与决策

| 决策 | 选择 | 理由 |
|------|------|------|
| persistent_store Store 类是否删除？ | **保留**（已标 DEPRECATED） | 11 个文件仍依赖 dict-like 接口；内部已委托 Repository；删除风险大收益小 |
| 53 个 schema 是否全量迁移？ | **是** | 保证 OpenAPI 生成类型一致性，避免前端混用 |
| openapi-typescript-codegen 版本？ | 0.29.0 | 稳定版本，支持 OpenAPI 3.0 |
| 删除 snakeToCamel 后前端字段如何处理？ | 全量替换为 camelCase | 后端 alias 已保证返回 camelCase |
| Alembic JSONB 迁移是否影响 SQLite？ | 否，dialect 判断 | 开发环境用 SQLite，生产用 PostgreSQL |

## 六、风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| snakeToCamel 删除后前端字段不匹配 | 高 | 高 | Task 5 完成后先验证后端返回 camelCase；Task 7 分批替换 |
| openapi-typescript-codegen 与现有 axios 不兼容 | 中 | 中 | 使用 `--client axios` 选项保持一致 |
| Alembic JSONB 迁移在 PostgreSQL 失败 | 低 | 高 | 迁移前备份；dialect 判断确保 SQLite 不受影响 |
| 53 个 schema 迁移引入序列化问题 | 低 | 中 | `populate_by_name=True` 保证 snake_case 仍可读 |
